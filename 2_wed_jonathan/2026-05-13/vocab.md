# Vocabulary & Grammar — 2026-05-13 (Passive Voice)

## Passive Voice — Structure

- [ ] **be + past participle** — основна формула пасивного стану
- [ ] **by** + agent — вказує хто виконав дію (часто опускається)

### Passive у різних часах

| Tense | Form | Example |
|-------|------|---------|
| Present Simple | is/are + V3 | The room **is cleaned** every day. |
| Past Simple | was/were + V3 | The contract **was signed** yesterday. |
| Present Continuous | is/are being + V3 | The files **are being uploaded** now. |
| Present Perfect | has/have been + V3 | The project **has been completed**. |
| Future Simple | will be + V3 | The results **will be announced** tomorrow. |
| Modal | modal + be + V3 | It **can be decided** later. |
| Infinitive passive | need/want + to be + V3 | It **needs to be decided**. |

---

## Passive — Key Characteristics

- [ ] **Formal** (not informal/conversational)
- [ ] **Academic** — common in reports, research writing
- [ ] **Writing** (more than speaking)
- [ ] **Objective** — removes personal responsibility ("Mistakes were made.")
- [ ] **Process-focused** — action/result matters, not who did it

## Grammar — Error Correction Patterns (passive)

- [ ] will be notified (NOT "will **been**") — modal + **be** + V3
- [ ] was seen **entering** (NOT "to entered") — see + object + -ing
- [ ] have the system **upgraded** (NOT "to be upgraded") — causative: have sth done
- [ ] are being dumped (NOT "**is** being") — plural subject → are
- [ ] should have **been made** a priority — modal perfect passive
- [ ] made the witness **sign** (NOT "made sign") — make + object + base form
- [ ] have **happened** (NOT "have **been** happened") — "happen" is intransitive, no passive
- [ ] objects to **being** interrupted (NOT "to be") — object to + -ing
- [ ] is reported **to be** planning — passive + to-infinitive
- [ ] will be **built** (NOT "builded") — irregular: build → built
- [ ] have **belonged** (NOT "have been belonged") — "belong" is stative, no passive
- [ ] must **be** stored (NOT "must **been**") — modal + be + V3
