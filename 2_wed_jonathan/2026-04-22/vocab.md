# Vocabulary & Grammar — 2026-04-22 (Inflation & Report Writing)

## Graph / Statistics Language

- [ ] rose sharply — різко зросло (e.g. Inflation rose sharply in 2022)
- [ ] increased gradually — поступово збільшилось
- [ ] reached a peak of — досягло піку в… (e.g. reached a peak of 72%)
- [ ] remained stable / steady — залишалось стабільним
- [ ] declined afterwards — потім знизилось
- [ ] noticeable — помітний (e.g. a noticeable rise)
- [ ] marginal — незначний, мінімальний (e.g. a marginal increase)
- [ ] downward / upward trend — спадна / висхідна тенденція
- [ ] fluctuate — коливатися (e.g. UK numbers fluctuated between 37–40m)
- [ ] volatile — нестабільний, мінливий (e.g. Turkey's inflation was highly volatile)
- [ ] sustained — тривалий, стійкий (e.g. sustained inflationary pressure)

## Report Writing Phrases

- [ ] steady upward movement — плавне зростання (3 words)
- [ ] sharp acceleration — різке прискорення (2 words)
- [ ] maintains / remains — зберігає (formal verb)
- [ ] gentle increase — плавне збільшення (2 words)
- [ ] double-digit levels — двозначні показники (>10%)
- [ ] small fluctuations — незначні коливання (2 words)
- [ ] from … onwards — починаючи з… (e.g. from 2018 onwards)
- [ ] it is likely that — малоймовірно / ймовірно що… (4-word phrase)
- [ ] vulnerable — вразливий (formal: at risk)
