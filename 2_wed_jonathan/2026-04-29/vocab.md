# Vocabulary & Grammar — 2026-04-29 (Grammar Corrections; Dabbawalas)

## Grammar Focus — Common Errors (SET 4)

- [ ] **despite** + noun / **in spite of** + noun (NOT "despite of")
- [ ] **negative inversion**: On no account **should** the alarm **be**… / Seldom **have we** witnessed…
- [ ] **look forward to** + -ing (NOT "to + verb")
- [ ] **result in** + -ing (NOT "result in + to")
- [ ] **such … that** (NOT "such … than")
- [ ] **past perfect continuous**: had been waiting (NOT "have been waiting" after "by the time")
- [ ] **insist that** + clause / **insist on** + -ing
- [ ] **neither … nor** (NOT "neither … or")
- [ ] **number of** (countable) vs **amount of** (uncountable) — tourists = countable → "number of tourists"
- [ ] **having been** (NOT "having being") — passive perfect gerund
- [ ] **no point in** + -ing / **it is pointless to** + verb
