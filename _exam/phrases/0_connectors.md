# Universal Connectors — Memorise All 15

> These work in ALL three task types. Learn once, use everywhere.
> Mark [x] when you can use it without thinking.

---

## Adding information
- [ ] **Furthermore,** — найсильніший, завжди формальний
- [ ] **In addition,** — нейтральний, безпечний
- [ ] **Moreover,** — підсилює попередню думку

## Contrasting
- [ ] **However,** — основний контраст (завжди після крапки + кома)
- [ ] **In contrast,** — порівняння двох речей
- [ ] **On the other hand,** — альтернативна точка зору

## Cause / Result
- [ ] **As a result,** — наслідок
- [ ] **Therefore,** — логічний висновок
- [ ] **Consequently,** — C1 рівень, замість "so"

## Conceding (поступка)
- [ ] **Although [S+V],** — хоча (не після крапки — в середині речення)
- [ ] **Despite [noun/gerund],** — незважаючи на (НІКОЛИ despite + that)
- [ ] **Even though [S+V],** — сильніше ніж although

## Example / Emphasis
- [ ] **For instance,** — приклад (= For example, але більш формальний)
- [ ] **In particular,** — підкреслення конкретного факту
- [ ] **Notably,** — C1 слово, звертає увагу

## Summary
- [ ] **In conclusion,** — тільки в останньому параграфі, ніколи раніше

---

> **Safe rule:** After a full stop → capital letter + comma.  
> `However, …` ✓ · `however` (no comma) ✗ · `However` (no comma) ✗
